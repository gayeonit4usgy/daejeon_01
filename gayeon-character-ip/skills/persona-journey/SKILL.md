# 퍼소나 & 여정지도 스킬

전체 규칙과 참고 파일(00-data-sources, 01-discovery, 02-persona-template, 03-journey-map, 04-insight-validation, 05-domain-adapters, frameworks, templates)은 함께 전달된 persona-journey.zip에 있다. 이 카드는 핵심 흐름만 담는다.

핵심: 결핍 있는 고객(Before)을 근거로 그리고, 여정지도로 막히는 지점을 찾고, 실제 데이터로 확인한 뒤, 되고 싶은 모습(After)을 같은 디테일로 보여준다.

## 단계 (각 단계 끝에 멈추고 확인받기)
0. 범위·비전: 대상, 목적, 시장, 설계/진단 모드, 분야 어댑터, 비전 한 줄
1. 근거 계획: 자체 데이터 요청 → 공개 데이터 목록 → Claude가 못 여는 곳은 '어디서·무엇을·얼마나·형태' 링크 요청 표(R1~)
2. STP·가설 고객 페르소나 2~4명 + 검증 가능한 가설 H1~Hn + 경쟁 지도
3. 여정지도: 단계 × (행동·생각·감정1~5·접점·고충·기회), 막히는 지점 2~3곳에 가설 ID 연결
4. 가설 검증: 플랫폼 2곳+, 시장별 분리, 별점 고르게, 지지:반박 집계, 10건 미만은 '약함', 새 주제는 새 ID
5. 반영: 검증 전→후 표시, After 페르소나, 변화 스토리, 포지셔닝 3대 검증
6. 활용: 여정 단계별 콘텐츠·CRM·제품 실행 표 + 다음 할 일

게이트 형식:
[단계 N 완료] 한 줄 결론 / 결과 3개 이내 / 근거 상태: 자체·공개·링크 대기 건수 / 확인해 주세요 1~3개 / 다음 단계

## 근거
순위: 자체 > 실사용 리뷰·인터뷰 > 플랫폼 수치 > 기사 > 추론. 태그: [자체] [리뷰] [공개] [사용자 링크] [가설] [가정]. 접근 차단 사이트는 우회하지 않고 사용자에게 요청.

## 규칙
숫자는 원문 확인 후 단위·시점과 함께. 모르면 '확인이 필요한 질문'. 실존 리뷰어 신원 미사용. 표본 치우침은 결과보다 먼저. 반박된 가설은 지우지 않고 '반박됨'.
