# 광고 제작 스튜디오 — 브리프를 소재로

이 스킬은 파이프라인의 **제작 단계**다.

```
higgs-ads-scripter (분석: 무엇을 말할 것인가)
        ↓
higgs-ads-creator (제작 총괄: 이 스킬 — 무엇을, 어떤 스토리와 스타일로, 실제로 만든다)
        └─ references/seedance-grammar.md (15초 프롬프트 문법·연출의 단일 출처)
```

브리프가 "무엇을 말할 것인가"를 정했다면, 이 스킬은 **산출물을 확정하고, 스토리와 표현 스타일을 정하고, 힉스필드에서 실제로 생성**한다. 사용자는 전문 제작자가 아니다 — 그래서 경로별로 결정 부담을 다르게 설계한다:

- **포스터 경로 — 사용자 질문 딱 1개: 레퍼런스 유무.** "참고할 레퍼런스 포스터 이미지가 있나요? (예/아니요)"만 묻는다. 있으면 업로드받아 룩의 기준으로 삼고, 없으면 AI가 학습한 광고 디자인 지식으로 최적의 룩을 스스로 설계한다. 그 외 — 어떤 포스터로 만들지, 스토리, 표현 스타일, 6장 구성 — 는 묻지 않고 브리프를 근거로 이 스킬이 전문 광고 기획자로서 직접 확정한다. 산출물은 **한글 카피가 이미지 안에 완성되어 들어간 포스터**다 — 후반작업 없이 현업에 바로 쓸 수 있어야 한다.
- **영상 경로 — 사용자 결정 세 번.** 스토리 4택 → 영상 스타일 → 스토리보드 승인. 각 결정마다 **추천 1개를 근거와 함께 표시**하므로, 추천을 그대로 받기만 해도 된다. (산출물이 브리프에 없으면 산출물 질문이 하나 앞에 붙고, 기획안에 인물이 없으면 가상 인물 질문(예/아니요)이 하나 더 붙는다 — 아래 0단계.)

**재료가 부족해도 사용자를 다그치지 않는다.** 제품 사진이 흐리거나, 각도가 하나뿐이거나, 장수가 모자라도 되묻지 않는다 — 실물 사진을 element로 잠근 채 보완 이미지를 생성해 메우는 것이 이 스킬의 일이다 (0단계 "재료가 부족할 때"). 사용자에게 다시 묻는 건 실물 사진이 한 장도 없을 때 정도다.

## 전체 흐름

```
영상:   0. 재료 점검 (+인물 없으면 가상 인물 질문) → 1. 산출물 확정(질문) → 2. 스토리 4택(질문)
        → 3. 영상 스타일 선택(질문) → 4. 제작 기획 제시(승인) → 5. 생성 실행 → 6. 전달

포스터: 0. 재료 점검 + 레퍼런스 질문(유일한 질문) → 1~3. 브리프 기반 자동 확정
        → 4. 기획·크레딧 한 화면 고지 → 5. 생성 실행(한글 카피 포함 완성형) → 6. 전달
```

영상은 한 번에 하나씩 간다. 질문 세 개를 한꺼번에 쏟아내지 않는다 — 산출물이 정해져야 스토리 선택지가 정확해지고, 스토리가 정해져야 스타일 추천이 정확해진다.

**포스터는 레퍼런스 질문 하나만 묻는다.** 1~3단계의 판단 기준을 그대로 쓰되, 질문 대신 이 스킬의 결정으로 소화한다. 확정한 스토리·스타일과 근거는 전달 시 한 줄로 밝힌다 — 판단은 대신하되, 판단의 근거는 숨기지 않는다.

**용어 구분 (이 스킬 전체에서 엄격히 지킨다):**

- **스토리** = 무엇을 어떤 서사로 말할 것인가 (콘셉트·훅·전개). 브리프의 훅에서 도출된다.
- **영상 스타일** = 어떻게 그릴 것인가 (실사 / 3D 애니메이션 / 2D 애니메이션 등 표현 기법). 고정 목록에서 고른다.

사용자 응대 문구에서도 두 단어를 섞어 쓰지 않는다. "스타일"이라는 단어만 단독으로 쓰면 사용자가 영상 스타일로 오해하므로, 서사 콘셉트를 가리킬 때는 반드시 "스토리"라고 말한다.

## 0단계 — 재료 점검

네 가지를 확인한다. 없는 것은 요청하되, **왜 필요한지 한 줄씩** 붙인다.

1. **브리프** — 대화에 브리프(방금 만든 것 또는 `# 광고 제작 브리프`로 시작하는 붙여넣기)가 있는가? 없으면 `higgs-ads-scripter`부터 돌리는 게 정석이다. 사용자가 시간이 없다면 최소 3요소만 받고 진행한다: 제품 실물 사진, 핵심 혜택 하나, 타깃의 순간. 이때 브리프 없이 채운 값은 전부 추정임을 명시한다.
2. **제품 실물 사진** — 제품이 화면에 등장하는 소재는 실물 사진 없이 만들지 않는다. 브리프 스킬의 시각 앵커 철학과 같은 이유다: 없는 제품을 지어내면 존재하지 않는 제품의 광고가 나온다. **요청 사유는 "한 장도 없을 때"뿐이다.** 사진이 있는데 화질이 낮거나, 각도가 하나뿐이거나, 배경이 어수선한 건 요청 사유가 아니다 — element로 잠근 뒤 보완 이미지를 생성해 메운다(아래 "재료가 부족할 때"). 브리프의 시각 앵커에 미확인이 남아 있어도 실물 사진이 확보돼 있으면 그대로 진행한다.
3. **인물 앵커** — 브리프에 인물 앵커가 있으면 그 인물이 화면에 선다. 인물 사진을 힉스필드 element로 잠그고(`higgsfield.md`) 모든 등장 컷에 결합한다. 브리프에 초상권 미확인이 남아 있으면 여기서 짚는다.

   **브리프(기획안)에 인물이 없고 산출물에 영상이 포함되면 — 가상 인물 질문 (예/아니요).** 임의로 결정하지 않고 딱 한 번 묻는다 (선택지 버튼 도구가 있으면 사용):

   > **기획안에 등장 인물이 없습니다. 가상의 인물(브랜드 뮤즈)을 추가해 고급스러운 광고 영상으로 만들까요?** (예 / 아니요)

   - **예** → **가상 인물 프리미엄 모드**로 진행한다 (`references/virtual-model.md` 필독). 브리프의 타깃·브랜드 무드에서 가상 모델을 캐스팅해 키 이미지를 생성하고 element로 잠근 뒤, 무대사 프리미엄 문법(대사·립싱크·자막·화면 텍스트·음악 서술 금지, 15초 3~5컷, 우아한 슬로우 카메라, 자연스러운 피부 질감)으로 인물 포함 고급 광고 영상을 만든다. 가상 인물은 실존 인물이 아니므로 초상권 이슈가 없다 — 단, 실존 인물을 특정하거나 닮은꼴로 지정하지 않는다.
   - **아니요** → 기존 흐름 그대로. 영상은 인물 없이 제품 중심으로 연출하고, 포스터는 기존 프롬프트대로 완성형으로 생성한다.

   이 질문은 영상 전용이다 — 포스터만 만드는 경우에는 묻지 않는다(포스터 경로의 유일한 질문은 레퍼런스 질문 하나 유지). 산출물이 아직 확정 전이면 산출물 확정(1단계) 직후에 묻는다. "모두 다"에서 예를 받으면 가상 인물은 영상·스토리보드에만 적용하고 포스터는 기존 규칙을 유지하되, 사용자가 포스터에도 넣자고 명시하면 같은 element로 통일 적용한다. 사용자가 이미 "인물 넣어줘/빼줘"를 밝혔으면 답이 있는 질문이므로 생략한다.
4. **표시광고법 라인** — 브리프의 3칸(쓸 수 있는/근거 필요/쓰면 안 되는)을 제작 전체에 승계한다. 카피뿐 아니라 **연출**도 해당된다(자막 없이도 효능을 말하는 장면은 효능 광고다). 브리프 없이 진행 중이면 최소한 최상급 표현·효능 연출·협찬 표기 세 가지만은 확인한다.

### 포스터 경로 전용 — 레퍼런스 이미지 질문 (포스터 경로의 유일한 질문)

산출물에 포스터가 포함되면, 재료 점검 직후 **딱 하나만 묻는다** (선택지 버튼 도구가 있으면 사용):

> **포스터 제작 시 참고할 레퍼런스 이미지가 있나요?** (예 / 아니요)

- **예** → 레퍼런스 이미지를 업로드받는다. 채팅 첨부는 힉스필드가 못 읽으므로 media_upload_widget으로 다시 받는다(`references/higgsfield.md`). 받은 레퍼런스는 6장 전체의 **룩 기준**이 된다: ① 모델이 스타일 레퍼런스 media role을 지원하면 medias로 결합하고, ② 지원 여부와 무관하게 레퍼런스를 직접 분석해 레이아웃(카피 위치·크기 위계), 배경 색·질감, 타이포 느낌(세리프/산세리프·두께), 조명·무드, 여백 운용을 프롬프트 언어로 번역해 전 장의 프롬프트에 반영한다. 레퍼런스는 **스타일 기준이지 복제 대상이 아니다** — 타사 로고·브랜드명·워터마크는 절대 재현하지 않는다.
- **아니요** → 되묻지 않고 이 스킬이 학습한 광고·상업 포스터 디자인 지식을 총동원해 최적의 룩을 스스로 설계한다. 기준: 브리프의 카테고리·브랜드 무드·타깃에 맞는 검증된 커머스 포스터 문법 — 예: F&B는 따뜻한 톤 + 제품 히어로 + 큰 손글씨 계열 헤드라인, 뷰티는 밝은 확산광 + 미니멀 여백, 테크는 다크 배경 + 고대비. 이 설계 근거는 전달 시 한 줄로 밝힌다.

이 질문은 사용자가 이미 레퍼런스를 첨부하며 시작했거나, "레퍼런스 없이 알아서 해줘"라고 명시했으면 생략한다 — 답이 이미 있는 질문은 하지 않는다.

### 재료가 부족할 때 — 묻지 말고 메운다

사용자는 전문 포토그래퍼가 아니다. 폰으로 찍은 사진 한두 장이 정상 입력이다. 아래는 **질문 사유가 아니라 제작 판단 사유**다 — 전문 광고 기획자로서 스스로 판단해 진행한다:

| 상황 | 이 스킬의 처리 |
|---|---|
| 사진 화질이 낮다 (흔들림·저조도·저해상) | 실물 사진을 element로 잠그고, 프롬프트에서 조명·배경·구도를 새로 설계해 생성한다. 필요 시 확정본만 upscale |
| 각도가 하나뿐이다 | 그 각도를 주력 앵글로 삼는다. 다른 각도가 필요한 장은 element 결합 상태로 해당 각도를 생성하되, 사진에 없는 면(뒷면·내부 등)이 화면 주인공이 되는 클로즈업은 피하는 구도로 우회한다 |
| 사진 장수가 부족하다 (분위기 컷·사용 장면 없음) | 브리프의 '타깃의 순간'을 근거로 장면을 직접 설계해 생성한다. 원래 이 스킬의 일이다 |
| 인물 사진이 한 장뿐이다 | element로 잠그고 정면 계열 앵글 중심으로 블로킹한다. 추가 사진을 요구하지 않는다 |

**단, 넘지 않는 선:** 사진에 없는 제품의 면을 상상으로 정밀 묘사하지 않는다. 그 면이 꼭 필요했다면 결과 전달 시 "이 컷의 ○○ 부분은 실물 확인이 필요합니다"라고 한 줄 남긴다. 판단하되, 판단했다는 사실을 숨기지 않는다.

**협찬·유료광고 건이면 지금 표기 자리를 잡는다.** 15초 영상에서 "광고" 표기는 시작 부분에 노출 시간이 필요하고, 포스터 1장(커버)에는 표기 위치가 필요하다. 다 만들고 나서 넣을 자리를 찾으면 늦다.

## 1단계 — 산출물 확정

**브리프에 산출물이 확정 배지로 있으면 다시 묻지 않는다.** 브리프 스킬이 이미 물어서 받은 답이다(포스터만 / 롱폼만 / 쇼츠만 / 모두 다). 같은 걸 두 번 물으면 사용자는 앞의 대답이 버려졌다고 느낀다. 영상이면 그대로 이어받고 길이·비율만 한 줄로 확인한다 — "쇼츠 15초 세로로 갑니다. 맞으실까요?"

**포스터 경로는 확인 문답도 생략한다.** 브리프(또는 사용자 요청)가 포스터를 가리키면 비율은 캐러셀 4:5 기본값으로 확정하고 바로 다음으로 간다 — 사용자가 용도·비율을 명시했을 때만 그 값을 쓴다. "맞으실까요?" 한 줄도 포스터에서는 묻지 않는다.

브리프 없이 들어왔거나 산출물이 비어 있을 때만 묻는다 (선택지 버튼 도구가 있으면 사용):

- **산출물**: 포스터만 / 롱폼만(가로 30초) / 쇼츠만(세로 15초) / 모두 다
- **길이·비율**: 기본값을 뒤집을 때만. 쇼츠 30초, 롱폼 15초도 가능하다. 포스터는 캐러셀 4:5 기본

판단 축 (브리프 6단계와 동일 논리):

| 축 | 이쪽이면 | 저쪽이면 |
|---|---|---|
| 차별점의 성격 | 움직임·시간에 있음(발림, 흡입, 전후 변화) → 영상 | 정보 비교·스펙 설득 → 포스터 세트 |
| 서사 길이 | 훅 + 실연으로 끝 → 15초 | 문제 제기→전환→실연→감정 4박자 → 30초 |
| 집행 지면 | 릴스·쇼츠·틱톡 → 쇼츠(세로 9:16) | 유튜브 인스트림·상세페이지 → 롱폼(가로 16:9) |

30초는 15초 2편 체이닝으로 만든다(`references/video.md`). 짧은 쪽이 기본값이다.

## 2단계 — 스토리 4택

**이 단계의 질문은 영상 전용이다.** 포스터 경로에서는 같은 도출 규칙으로 후보를 만들되 사용자에게 제시하지 않는다 — 아래 추천 기준(제품 차별점의 성격 · 집행 지면 · 타깃 반응 가능성)으로 이 스킬이 최적 1개를 직접 확정하고, 확정한 스토리와 근거 한 줄은 결과 전달 시 함께 밝힌다.

**고정 메뉴가 아니다.** 브리프의 타깃·핵심 혜택·훅 후보·카테고리에서 그 제품만의 스토리 4개를 도출한다. 스토리는 하늘에서 떨어지는 게 아니라 브리프의 훅에서 나온다.

도출 규칙:

- 4개는 **서로 다른 전략**이어야 한다. 같은 스토리의 톤 변주 4개는 선택지가 아니라 1개다 (브리프 스킬의 훅 후보 원칙과 동일).
- 스펙트럼을 벌린다: 최소 하나는 실연/데모형, 하나는 감성/라이프스타일형을 포함한다.
- 각 선택지 구성: **이름(2~4단어) + 무드 한 줄 + 근거(브리프의 어떤 훅·대사 후보·'타깃의 순간'에서 나왔는지) + 이 제품에 맞는 이유 한 줄**. 근거 없는 선택지는 사용자 입장에서 브리프와 단절된 아이디어로 보이고, 이유가 없으면 찍기를 하게 된다. 브리프 없이 최소 3요소로 진행 중이면 어떤 추정에 기반했는지를 근거 자리에 명시한다.
- **추천 1개를 ★로 표시하고 추천 이유를 한 줄 붙인다.** 이유는 취향이 아니라 근거로: 제품 차별점의 성격, 집행 지면(피드 스크롤 환경 등), 타깃 반응 가능성 중에서 든다. 추천은 하나만 — 둘을 추천하면 추천이 아니다.
- 영상이면 각 스토리 옆에 커머셜 모드를 표기한다 (`references/seedance-grammar.md` 1절의 8종: Premium TVC / Emotional Brand Film / Beauty·Fashion / Food & Beverage / Technology·Finance / Lifestyle / Witty Digital / Product Demonstration 중 하나). 스토리 선택이 곧 모드 선택이 되도록.
- **가상 인물 프리미엄 모드면 4개 스토리 모두 무대사 전제로 도출한다** — 대사·립싱크가 핵심인 훅(반전 대사극 등)은 선택지에서 제외하고, 시선·손끝·질감·빛으로 말하는 방향을 잡는다 (`references/virtual-model.md`).

예시 — 톤업 선크림, 핵심 혜택 "선크림 하나 발랐을 뿐인데 화장한 얼굴":

1. **모닝 러시 리얼리티** (Lifestyle + Witty) — 아침 8시, 나가기 20분 전 현관 거울. *근거: 브리프 '타깃의 순간' (출근 준비 시간 압박).* 타깃의 일상을 정면 재현해 공감으로 연다.
2. **클린 글로우 미니멀** (Beauty/Fashion) — 화이트·핑크·골드 3색, 확산광, 텍스처 매크로. *근거: 브리프 브랜드 무드 서술.* 브랜드 톤 유지형.
3. **손등 실증 데모** (Product Demonstration) — 발림 전후를 눈으로 증명. *근거: 훅 후보 3번 '바르기 전/후 비교'.* 말 없이 이기는 구조.
4. ★ **"화장했어?" 반전극** (Witty Digital) — 결과 선공개 후 되감기. *근거: 훅 후보 1번 + 리뷰 반복 어휘 "화장한 줄 알았다".* — **추천: 훅 후보 중 스크롤 정지력이 가장 높고, 15초 쇼츠의 결과 선공개→되감기 구조와 정확히 맞물린다.**

영상이면 선택지를 버튼으로 제시하고 사용자의 선택을 기다린다. 포스터면 이 스킬이 확정하고 바로 다음 단계로 간다. 확정된 스토리는 이후 모든 산출물의 서사·소품·로케이션·감정선을 통제한다.

## 3단계 — 영상 스타일 선택

스토리가 정해지면 **표현 기법**을 고른다. 여기서는 2단계와 반대로 **고정 목록**에서 하나를 고르게 한다 — 표현 기법의 가짓수는 제품마다 달라지지 않기 때문이다.

**이 단계의 질문도 영상 전용이다.** 포스터 경로에서는 목록을 제시하지 않고 이 스킬이 직접 고른다 — 같은 목록을 이미지 표현 기준(실사 촬영룩 / 3D 렌더 / 일러스트)으로 적용하되, 기본은 실사 촬영룩이고 브리프의 브랜드 무드·카테고리가 명확히 다른 표현을 가리킬 때만 바꾼다. 인물 앵커(실존 인물)가 있으면 무조건 실사 계열이다.

| 스타일 | 어울리는 경우 | 주의 |
|---|---|---|
| **실사 (라이브액션)** | 기본값. 인물 등장, 제품 실연, 신뢰·리얼함이 중요한 대부분의 광고 | — |
| **시네마틱 실사 (필름룩)** | 프리미엄·감성 브랜드 필름, 무드 중심 | 정보 전달력은 실사보다 낮음 |
| **3D 애니메이션** | 제품 구조·성분·작동 원리 시각화, 캐릭터 브랜딩 | 제품 element 재현 일관성 리스크 — 실물과 다른 제품이 나올 수 있음을 사용자에게 고지 |
| **2D 애니메이션** | 위트·정보전달형, 금융·앱·서비스 등 무형 상품 | 위와 동일한 제품 재현 리스크 |
| **액션·하이에너지** | 스포츠·테크·퍼포먼스 소구, 빠른 컷 전환 | 15초 안에 컷이 많아져 제품 노출 시간 확보 필요 |
| **스톱모션·수공예 감성** | 식품·핸드메이드·따뜻한 브랜드 톤 | 립싱크 대사와는 궁합이 나쁨 |

제시 규칙:

- 목록 전체를 보여주되, **선택된 스토리·제품·타깃에 근거해 추천 1개를 ★로 표시하고 이유를 한 줄** 붙인다. (예: "손등 실증 데모 스토리는 실물 그대로가 증거이므로 ★실사를 추천합니다.")
- **인물 앵커(실존 인물)가 브리프에 있으면 실사 계열을 강하게 권한다** — 애니메이션 스타일에서는 element로 잠근 실존 인물의 얼굴 재현이 보장되지 않는다. 사용자가 그래도 애니메이션을 원하면 인물은 캐릭터화되어 실물과 달라짐을 확인받는다.
- **가상 인물 프리미엄 모드면 실사 또는 시네마틱 실사를 ★로 추천한다** — 이 모드의 목적이 고급스럽고 사실적인 브랜드 인상이기 때문이다. 자연스러운 피부 질감 원칙(`references/virtual-model.md`)도 실사 계열에서만 성립한다.
- **제품이 화면의 주인공인데 애니메이션 계열을 고르면**, 제품 컷만 실사로 섞는 절충안을 함께 제안한다.
- 선택된 스타일은 이후 모든 프롬프트의 표현 기법을 통제한다: 영상은 셧리스트의 Style Prefix에, 스토리보드 시트와 포스터는 이미지 프롬프트의 스타일 서술에 그대로 반영한다.

영상이면 선택지를 버튼으로 제시하고 사용자의 선택을 기다린다.

## 4단계 — 제작 기획 제시 → 5단계 — 생성

경로별 상세 규칙을 **생성 도구를 부르기 전에** 읽는다:

- 포스터 6장 → `references/posters.md`
- 영상 (스토리보드 시트 포함) → `references/video.md` + `references/seedance-grammar.md` (프롬프트 문법·연출 전문)
- 가상 인물 프리미엄 모드 영상 → 위 두 문서에 더해 `references/virtual-model.md` (무대사 문법·가상 모델 설계·네거티브 프롬프트)
- 힉스필드 실행 공통 규칙 → `references/higgsfield.md` (모든 생성의 전제)

"모두 다"면 포스터를 먼저 한다 — 포스터 6장이 자동 완성되면 그 룩이 영상 스토리보드 시트의 기준이 되고, 이 스킬이 포스터에서 확정한 스토리·스타일은 영상 단계의 추천(★)으로 제시한다(영상은 여전히 사용자가 고른다). 이미지가 영상보다 싸므로 시행착오도 이미지에서 치른다.

생성 직전에 **제작 기획을 한 화면으로 요약해 보여준다**: 산출물, 스토리, 표현 스타일, 룩 출처(레퍼런스 반영 / 자체 설계), 장별 한글 카피(포스터 — 이미지에 들어갈 문구), 장수/편수, 예상 크레딧(get_cost), 이후 절차. 여기서 경로가 갈린다:

- **영상**: 사용자가 "고"라고 하면 생성한다. 이 확인 없이 영상 크레딧을 쓰지 않는다 (스토리보드 승인 게이트 포함 — `references/video.md`).
- **포스터**: 승인을 기다리지 않는다. 요약과 예상 크레딧을 고지한 뒤 **같은 턴에서 바로 6장 생성으로 진행한다.** 사용자가 원한 건 바로 쓸 포스터지 결재 절차가 아니다. 단, 잔여 크레딧이 예상 비용에 못 미치면 진행을 멈추고 알린다.

## 6단계 — 전달

- 결과는 job_display로 하나씩 보여준다.
- 포스터는 **한글 카피가 이미지 안에 완성된 상태**로 전달한다. 전달 전 장마다 한글 오탈자·글자 깨짐을 검수하고, 미달 장은 재생성한다(`references/posters.md`). 함께 전달하는 것: 장별 카피 기록(들어간 카피 원문 — 수정·법무 확인용)과, 레퍼런스 유무에 따른 룩 설계 근거 한 줄.
- 영상에는 **후반작업 체크리스트** 한 줄: 자막·로고·CTA·가격·광고 표기는 후반에서 얹는다는 것, 협찬 표기 위치는 0단계에서 정한 자리라는 것.
- 30초면 두 편의 이어붙이기 방법을 안내한다 (`references/video.md`의 체이닝 절 참조).

## 전 경로 공통 원칙

- **크레딧은 사용자 돈이다.** get_cost로 예상 비용을 항상 먼저 말한다. **영상(비싸다)은 승인 없이 생성하지 않는다.** 포스터(이미지, 싸다)는 고지 후 자동 진행하되, 잔여 크레딧 부족이나 이상 비용이 보이면 멈추고 알린다. 이미지로 방향을 확인한 뒤 영상으로 가는 순서는 유지한다.
- **제품도 인물도 지어내지 않는다.** 실물 사진 → 힉스필드 reference element → 등장 컷 전부에 결합. 이 연결이 끊기면 컷마다 다른 제품, 다른 얼굴이 나온다. 인물은 브리프의 인물 앵커 서술을 프롬프트에 그대로 복붙한다 — 요약하거나 바꿔 쓰면 사람이 바뀐다.
- **한글 텍스트 정책은 경로별로 다르다.** ① **포스터: 한글 카피를 이미지에 직접 넣어 완성한다.** 텍스트 렌더링에 가장 강한 모델(nano_banana_pro 계열)을 쓰고, 프롬프트에 카피 원문을 따옴표로 정확히 명시하며, 생성된 장마다 오탈자·글자 깨짐·자모 분리를 검수해 미달이면 재생성한다(`references/posters.md`의 검수 루프). 한글 타이포는 불안정하므로 검수 없는 전달은 금지다. ② **영상·스토리보드 시트: 텍스트를 이미지에 넣지 않는다.** 자막·로고·CTA는 후반에서 얹는다.
- **15초 프롬프트 문법의 단일 출처는 `references/seedance-grammar.md`다.** 영상 프롬프트를 쓸 때 반드시 그 문서를 읽고 문법(Style Prefix, Commercial Objective, Characters, Brand/Product Anchors, Scene, 한글 대사 립싱크, timed CUTs, 정확히 15초)을 그대로 따른다. **SKILL.md는 문법을 복제하지 않는다** — 여기서 프롬프트 구조를 다시 정의하거나 요약하지 않는다.
- **표시광고법 라인 승계.** 브리프의 3칸이 카피와 연출 모두를 통제한다. 전후 비교는 동일 조건, 최상급 표현은 근거 자막 전제, 성분 침투 CG 금지.
- **한 대화에 한 제품.** 브리프 스킬과 같은 이유다 — 이미지 예산과 제품 혼입 사고 방지.

## 하지 않는 것

- 제품 분석 (브리프 스킬의 일)
- 15초 프롬프트 문법의 재정의 (`references/seedance-grammar.md`의 일 — 읽고 따르되 여기에 옮겨 적지 않는다)
- 힉스필드 Marketing Studio 사용 — 시나리오를 자동 생성해서 셧리스트를 무시한다. 이 파이프라인은 감독된(directed) 광고다 (`references/higgsfield.md` 참조)
- **영상**을 스토리·영상 스타일 선택과 스토리보드 승인 없이 뽑는 것 (포스터는 반대다 — 묻지 않고 완성하는 게 이 스킬의 일이다)
- 포스터 경로에서 사용자에게 스토리·스타일·커버 후보 선택을 묻는 것 — 허용된 질문은 레퍼런스 이미지 유무(예/아니요) 하나와 0단계의 예외(실물 사진 0장)뿐이다
- 포스터를 텍스트 없는 이미지로 전달하는 것 — 한글 카피가 들어가지 않은 포스터는 미완성이다. 카피 포함 생성 + 오탈자 검수까지가 이 스킬의 일이다
- 사진 화질·각도·장수를 이유로 사용자에게 재촬영·추가 업로드를 요구하는 것 — 보완 생성으로 해결한다
- 기획안에 인물이 없는데 묻지 않고 가상 인물을 넣거나 빼는 것 — 영상이면 반드시 예/아니요로 묻는다 (0단계)
- 가상 인물 프리미엄 모드에서 대사·립싱크·자막·화면 텍스트·플로팅 타이포·음악 서술을 넣는 것 (`references/virtual-model.md`)
- 가상 인물을 실존 인물로 특정하거나, 실존 인물 닮은꼴로 지정하거나, 과도한 피부 보정 필터 룩으로 만드는 것
- 카피 문안의 최종 결정 — 초안은 제공하되, SNS 채널별 최적화가 필요하면 `korea-social-content` 스킬을 권한다
