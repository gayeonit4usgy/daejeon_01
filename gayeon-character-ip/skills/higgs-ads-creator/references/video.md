# 영상 — 셧리스트 → 스토리보드 → 생성 (15초 / 30초)

## 순서가 곧 안전장치다

```
셧리스트(글, 무료) → 스토리보드 시트 1장(이미지, 싸다) → 사용자 승인 → 영상(비싸다)
```

셧리스트 없이 영상 프롬프트를 쓰지 않고, 스토리보드 승인 없이 영상을 생성하지 않는다. 영상 생성은 이 파이프라인에서 가장 비싼 단계이므로, 방향 착오는 전부 그 앞에서 걸러낸다. 사용자가 명시적으로 스토리보드를 건너뛰자고 하면 그건 사용자의 선택이다 — 크레딧 리스크를 한 줄로 알리고 진행한다.

## 1. 셧리스트

`seedance-grammar.md`를 읽고 **그 문법 그대로** 작성한다 (Style Prefix → Commercial Objective → Characters → Brand/Product Anchors → Scene → Dialogue & Lip Sync → timed CUTs, 정확히 15초, 한글 대사 + 립싱크 지시, 자막·로고·엔드카드 금지). 이 스킬이 추가로 정하는 것만 아래에 적는다.

- **모드**: 2단계에서 선택된 스토리에 표기된 모드를 쓴다. `seedance-grammar.md` 1절은 모드의 **정의**이지 선택 절차가 아니다 — 거기서 다시 고르지 않는다.
- **영상 스타일**: 3단계에서 선택된 영상 스타일(실사/시네마틱/3D·2D 애니메이션 등)을 Style Prefix에 반영한다. 문법 문서의 기본 실사 톤과 다른 스타일이 선택됐어도 셧리스트 구조(Characters, Anchors, timed CUTs)는 동일하게 유지한다.
- **비율 프레이밍**: 9:16이면 프롬프트의 카메라·구도 지시를 세로에 맞춘다 — 단독 피사체 중심, 수직 구도, 와이드 투샷과 좌우로 긴 테이블탑 지양, 클로즈업 비중 상향. 16:9는 감독 기본값 그대로.
- **편수**: 15초 = 프롬프트 1개. 30초 = 프롬프트 2개(아래 체이닝).
- **가상 인물 프리미엄 모드**(0단계 질문 "예"): `virtual-model.md`를 함께 읽는다. Dialogue & Lip Sync 블록을 무대사 선언으로 대체하고, 15초 3~5컷·우아한 슬로우 카메라·네거티브 프롬프트 블록을 적용한다. Characters 블록에는 확정된 가상 모델 외형 서술을 복붙하고 가상 모델 element를 결합한다. `seedance-grammar.md`의 한글 대사·립싱크 절은 이 모드에서 적용하지 않는다 — 나머지 구조는 동일(오버라이드 범위는 문법 문서 상단 표 참조).

## 2. 30초 = 15초 × 2 체이닝

Seedance 프롬프트 단위는 15초 고정이다(`seedance-grammar.md` 문법 상수). 30초 광고는 **독립적으로 생성되는 두 편을 편집에서 이어붙이는 것**이므로, 승부처는 이음새다.

**서사 배분:**

- Part 1 (0–15s): 훅 + 문제/공감 + 전환의 시작. 마지막 컷은 동작의 중간이 아니라 **상태의 완결**에서 끝낸다 — 편집점이 자연스러우려면 멈출 수 있는 순간이어야 한다 (예: 제품을 집어 든 채 카메라를 보는 정지 비트 ○ / 팔을 휘두르는 도중 ×).
- Part 2 (15–30s): 실연 + 감정 + 제품 마무리 비트. 첫 컷은 Part 1의 마지막 상태와 **같은 순간**이되, 새 앵글로 시작해도 된다(매치컷).

**CONTINUITY 규칙 — Part 2 프롬프트에 명시할 것:**

- Part 1 마지막 컷의 상태 = Part 2 첫 컷의 상태: 인물의 위치·자세·의상·헤어·감정, 제품의 상태(개봉 여부·잔량·손 위치·물기), 로케이션·시간대·광원 방향.
- 두 프롬프트의 **Characters 블록과 Brand/Product Anchors 블록은 단어 단위로 동일하게 복붙**한다. "비슷하게"가 아니라 동일하게 — 서술이 한 단어 다르면 다른 사람, 다른 제품이 나온다.
- Part 2의 Scene 블록 첫 줄에 이어짐을 선언한다: "Continuing directly from the previous 15-second unit: [Part 1 마지막 컷의 상태 요약]".

**생성 순서**: Part 1 생성 → 결과 확인 → Part 2 생성. Part 1이 틀렸는데 Part 2까지 뽑으면 손해가 두 배다. Part 1의 마지막 프레임이 의도와 다르면 Part 2의 CONTINUITY 서술을 **생성된 실제 화면**에 맞춰 고친 뒤 뽑는다 — 계획이 아니라 실물에 잇는다.

**이어붙이기**: 후반 편집에서. 힉스필드 안에서 단순 연결이 필요하면 explainer_video로 두 job_id를 순서대로 잇는다(무료 조립). 자막·로고는 여전히 후반이다.

## 3. 스토리보드 — 4K 한 장짜리 시트

목적: 영상 크레딧을 쓰기 전 **방향 승인 게이트**. 사용자가 스토리(2단계)와 영상 스타일(3단계)을 선택한 뒤에 만든다.

**컷별로 이미지를 한 장씩 뽑지 않는다. 전 컷을 담은 스토리보드 시트 1장을 4K로 생성한다.** 모든 산출물이 30초 이내(15초 = 컷 1~4개, 30초 = 두 편 합쳐 최대 8컷)이므로 한 장의 그리드로 충분하다. 낱장 방식보다 크레딧이 적게 들고, 컷 간 일관성(같은 인물·같은 제품·같은 룩)을 한 번의 생성 안에서 잡을 수 있으며, 사용자가 전체 흐름을 한눈에 승인할 수 있다.

**시트 프롬프트 구성 (영문):**

- 도입부: "professional film storyboard sheet, N panels arranged in a X×Y grid, clean white gutters between panels, panel numbers only (no other text)" — 컷 수에 맞는 그리드를 명시한다 (예: 4컷 = 2×2, 8컷 = 4×2).
- 패널마다 해당 CUT의 카메라·렌즈·조명·블로킹 서술을 **정지화상으로 번역**해 "Panel 1: …" 형식으로 적는다. 그 컷의 시작 프레임이 아니라 **그 컷이 말하고자 하는 대표 순간** 하나를 고른다 (실연 컷이면 차이가 보이는 순간, 대사 컷이면 표정이 사는 순간).
- 3단계에서 선택된 영상 스타일 서술을 시트 전체 스타일로 반영한다.
- 일관성: 제품 element 결합 + Characters 블록의 인물 외형 서술을 시트 프롬프트에 복붙하고 "same person and same product in every panel"을 명시한다. 가상 인물 프리미엄 모드면 키 이미지에서 잠근 가상 모델 element도 함께 결합한다(`virtual-model.md` 2절) — 사용자는 이 시트 승인으로 모델의 룩까지 함께 승인한다.
- 패널 내부 프레이밍은 영상 비율(9:16/16:9)에 맞춘다 — 9:16 영상이면 세로형 패널 그리드. 패널 번호(숫자) 외 텍스트·자막·로고 금지(문법 문서의 후반작업 경계와 동일).

**4K 해상도:** 패널이 여러 개 들어가므로 낱장보다 해상도가 중요하다. 모델이 4K(또는 최고 해상도) 직접 생성을 지원하면 그 옵션으로 생성하고, 지원하지 않으면 생성 직후 upscale_image로 4K 업스케일해 각 컷의 디테일이 보이게 한 뒤 제시한다. 30초(8컷)는 그리드가 빽빽하므로 업스케일을 생략하지 않는다.

**제시 형식:** 시트 이미지 1장 + 컷 표(컷 번호 · 타임코드 · 한 줄 설명 · 대사). 사용자가 특정 컷을 고치자고 하면 피드백을 모두 모은 뒤 **시트 전체를 1회 재생성**한다(한 장이므로 부분 재생성이 없다 — 컷별 피드백이 여러 개면 모아서 한 번에). 수정 사항은 셧리스트의 해당 CUT에도 반영한다 — 스토리보드와 셧리스트가 어긋난 채 영상으로 가면 승인이 무효가 된다.

**첫 프레임 소재:** 시트는 승인 게이트 전용이다. 모델이 image-to-video 첫 프레임을 지원하고 그걸 쓰기로 하면, **승인 후** 해당 컷만 단독 키프레임 1장을 영상 비율로 별도 생성한다(시트를 잘라 쓰지 않는다 — 그리드 패널은 첫 프레임 소재로 품질이 부족하다).

## 4. 영상 생성

`higgsfield.md`의 실행 규칙 위에서:

- model: `seedance_2_0`. **Marketing Studio 계열 금지** — 시나리오를 자동 생성해서 셧리스트를 무시한다.
- prompt: 셧리스트의 프롬프트 **전문** (Style Prefix부터 마지막 CUT까지, 문법 문서의 "각 프롬프트는 단독으로 완결" 원칙 그대로). 제품 element는 Brand/Product Anchors 서술 안에 `<<<element_id>>>`로 결합.
- aspect_ratio를 항상 명시한다('9:16'/'16:9') — 기본값에 맡기지 않는다. duration은 models_explore로 지원값을 확인해 15초 단위에 맞춘다.
- get_cost 프리플라이트 → 예상 크레딧 보고 → 승인 → 생성. image-to-video 첫 프레임 지원 여부는 models_explore로 확인하고, 쓰기로 했다면 스토리보드 승인 후 별도 생성한 단독 키프레임(3절 참조)의 job_id를 medias로 전달한다 — 스토리보드 시트 자체를 첫 프레임으로 넣지 않는다.

## 5. 후반작업 경계 (문법 문서 승계)

자막·카피·로고·CTA·가격·광고 표기 = 전부 후반. 단 **협찬 표기는 영상 시작부에 노출 시간이 필요**하므로, 0단계에서 정한 표기 위치를 전달 노트에 남긴다. 가격은 영상에 박지 않는다 — 가격은 바뀌고 영상은 남는다.
