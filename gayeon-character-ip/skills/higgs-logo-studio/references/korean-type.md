# 한글 로고 — 검수와 우회

브랜드명에 한글이 들어가면 읽는다. 영문 전용이면 이 문서는 건너뛴다.

## 왜 따로 다루는가

이미지 모델의 한글 렌더링은 2026년 현재도 불안정하다. 포스터라면 한 글자 틀려도 재생성하면 그만이지만, **로고는 글자 하나가 틀리면 물건 전체가 폐기된다.** 간판에 달고 명함을 찍은 뒤에 발견하면 되돌릴 수 없다.

그리고 초보자는 **틀린 걸 못 알아본다.** 자모가 미묘하게 분리된 로고를 보고 "디자인이 원래 이런가 보다"라고 넘긴다. 그래서 검수는 사용자가 아니라 스킬의 일이다.

## 검수 체크리스트

생성된 한글 로고를 **매번** 이 순서로 본다. 하나라도 걸리면 사용자에게 보이기 전에 재생성한다.

1. **자모 분리** — `안` 이 `ㅇㅏㄴ` 으로 흩어졌는가. 받침이 떨어져 나갔는가
2. **유령 글자** — 요청하지 않은 글자·기호가 붙었는가. 모델이 여백을 글자로 메우려 드는 일이 잦다
3. **글자 수** — 요청한 글자 수와 같은가. 한 글자가 통째로 빠지거나 늘어나는 경우가 있다
4. **획 뭉갬** — 복잡한 받침(ㄻ, ㅄ)이나 이중모음(ㅢ, ㅚ)이 덩어리로 뭉갰는가
5. **엉뚱한 글자** — 형태가 비슷한 다른 글자로 바뀌었는가 (`곰`↔`끔`, `물`↔`불`)

**의심스러우면 틀린 것으로 간주한다.** 로고에서 애매한 글자는 애매한 채로 인쇄된다.

## 2스트라이크 규칙

같은 프롬프트로 **2회 재생성해도 글자가 안 나오면 방향을 바꾼다.** 3회, 4회 반복은 크레딧만 태운다. 모델이 그 글자를 못 그리는 것이지 운이 나쁜 게 아니다.

우회 경로:

> **심볼만 확정하고, 글자는 실제 폰트로 얹는다.**

1. 프롬프트에서 브랜드명을 **빼고** 심볼만 생성한다 (negative에 `no text, no letters, symbol only` 추가)
2. 심볼이 확정되면 `logo_qa.py`로 투명 PNG를 만든다
3. 사용자에게 **추천 폰트 + 조립 방법**을 안내한다

이게 오히려 결과가 낫다. 실제 폰트로 얹은 글자는 **항상 정확하고, 크기를 바꿔도 안 뭉개지고, 나중에 수정도 된다.** AI가 그린 글자는 셋 다 안 된다. 우회가 아니라 상위 호환인 경우가 많다는 뜻이다 — 사용자에게도 그렇게 설명한다. "실패해서 이렇게 합니다"가 아니라 "이 방법이 더 정확합니다"가 맞는 말이다.

## 조립 방법 안내 (초보자용)

전문 디자인 툴을 요구하지 않는다. 사용자가 이미 아는 것으로 안내한다.

| 도구 | 안내 |
|---|---|
| **파워포인트** | 투명 PNG 삽입 → 텍스트 상자에 브랜드명 → 추천 폰트 적용 → 슬라이드 크기를 정사각형으로 → **PNG로 저장**(그림으로 저장). 오피스가 익숙한 사용자에게 가장 빠르다 |
| **미리캔버스 / 캔바** | 웹에서 무료. 한글 폰트가 내장돼 있고 투명 PNG 내보내기가 된다 |

파워포인트를 먼저 권한다. 초보자에게 새 도구를 배우게 하는 것보다, 아는 도구로 끝내게 하는 편이 실제로 완성될 확률이 높다.

## 무료 상업용 한글 폰트

Q4에서 고른 느낌에 맞춰 **2~3개만** 추천한다. 목록을 통째로 던지면 초보자는 못 고른다.

| 느낌 | 추천 |
|---|---|
| **깔끔·정돈** | 프리텐다드(Pretendard), 스포카 한 산스 Neo, 노토 산스 KR |
| **따뜻·손맛** | 카페24 써라운드, 온글잎 시리즈, 나눔손글씨 |
| **고급·클래식** | 마루부리, 리디바탕, 나눔명조 |
| **재미·개성** | 배달의민족 주아·한나, 여기어때 잘난체, 지마켓 산스 |

굵기가 여러 벌 있는 폰트(프리텐다드, 노토 산스 KR)를 우선한다. 로고는 굵게, 본문은 보통으로 — 한 가족 안에서 톤을 맞출 수 있다.

## 상표 등록을 계획한다면 — 폰트 라이선스 함정

**여기가 초보자가 가장 크게 다치는 지점이다.**

"무료 상업용 폰트"라는 말은 대개 *사용*이 무료라는 뜻이지, **그 폰트로 만든 로고를 상표로 등록해도 된다는 뜻이 아니다.** 무료 배포 폰트 중 상당수가 라이선스에 "폰트를 이용한 로고의 상표권 등록 제한" 조항을 두고 있다. 간판까지 달고 나서 상표 출원 단계에서 막히면 되돌리기 어렵다.

그래서 사용자가 **상표 등록 의사를 비치면** 이렇게 안내한다:

1. 쓰려는 폰트의 배포처에서 **라이선스 전문의 '상표권 등록' 조항을 확인**할 것
2. 조항이 모호하면 배포처에 문의하거나, 제한이 없는 폰트로 바꿀 것
3. 확실한 길은 **글자를 폰트 그대로 쓰지 않고 형태를 변형**하는 것이다 (자간·획 굵기·일부 획 커스텀). 이러면 폰트가 아니라 독자 디자인이 된다
4. 규모가 있는 사업이면 이 단계에서 디자이너·변리사를 만나는 게 맞다

**라이선스 조건은 배포처가 언제든 바꿀 수 있으므로, 스킬이 "이 폰트는 등록 가능합니다"라고 단정하지 않는다.** 확인해야 할 지점이 있다는 사실을 알려주는 것까지가 스킬의 몫이다. 이건 겁주기가 아니라, 모르고 지나가면 나중에 훨씬 비싸지는 종류의 정보다.

## 상표 검색

모든 한글 로고 전달 시 한 줄 덧붙인다: **특허청 키프리스(kipris.or.kr)에서 같은 업종에 비슷한 이름·표장이 이미 있는지 무료로 검색할 수 있다.** 스킬은 검색을 권할 뿐, 등록 가능 여부를 판단하지 않는다 — 그건 변리사의 일이다.
