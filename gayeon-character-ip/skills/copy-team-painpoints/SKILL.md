# 카피팀 — 페인포인트·미해결과제 100 → 추리기

## 0. 입력 확인 (질문은 한 번에, 최소로)
- 필수: 무엇(브랜드/제품/서비스 또는 주제), 누구(타깃)
- 선택: 사용 상황, 경쟁 제품, 리뷰·URL·자료
- 필수가 빠졌을 때만 한 번에 묻는다. 자료가 있으면 먼저 읽고 근거로 쓴다.

## 1. 100개 도출
- 페인포인트 50개: 지금 겪는 불편·짜증·불안·손해
- 미해결과제 50개: 하고 싶은데 아직 못 하고 있는 일(JTBD), 기존 해결책이 채워주지 못하는 것
- 고객 여정 전 단계에 고르게 분포: 인지 → 탐색·비교 → 구매 → 사용 → 사후/재구매
- 기능적 / 정서적 / 사회적 차원을 섞는다
- 각 항목은 고객 입말 한 줄 (예: "바를 땐 촉촉한데 오후면 당겨서 또 꺼내야 함")
- 금지: 중복, "불편함" 같은 추상어, 지어낸 통계
- 근거 태그: [리뷰] 실제 자료 기반 / [가설] 추정

## 2. 1차 필터 (100 → 약 30)
제외 기준을 명시하고 걸러낸다:
- 의미 중복 → 하나로 병합
- 너무 추상적이거나 일반적인 것
- 이 제품/서비스가 해결할 수 없는 것

## 3. 2차 점수 (30 → Top 10)
항목마다 1~5점:
- 강도: 얼마나 아픈가
- 빈도: 얼마나 자주·많이 겪는가
- 해결 부재: 기존 대안이 못 풀고 있는가
- 우리 해결력: 이 제품이 증명 가능하게 푸는가
- 카피 훅: 한 줄로 찔렀을 때 "어, 내 얘기"가 나오는가
합계 순 Top 10, 동점이면 카피 훅 우선.

## 4. 최종 (Top 3 + 카피 앵글)
- Top 3 각각: 왜 골랐는지 한 줄 + 카피 앵글 + 헤드라인 시안 2개
- 표시광고법 리스크 있는 표현(최고·완벽·효과 단정 등)은 피하고, 있으면 짚는다.

## 출력
- 100개 전체는 정렬·필터 가능한 표(Sheets 타입 우선)로: 번호 / 구분(페인·미해결) / 여정단계 / 차원 / 내용 / 근거태그 / 1차통과 / 점수
- 답변에는 1차 필터 기준 요약, Top 10 표, Top 3 + 카피 시안만 간결하게.
