# MVP 조사 설계서 만들기

매일 손으로 하던 조사를 AI 에이전트로 줄이는 MVP의 **조사 설계서 한 장(mvp.md)**과 **한눈에 보는 HTML 페이지**를 만든다. 직무, 회사, 채용공고가 바뀌어도 같은 틀로 만든다. 모든 결과는 한국어로, 쉬운 말로 쓴다.

## 1단계. 먼저 질문하기 (한 번에, 최대 4개)

사용자 메시지에 이미 답이 있는 항목은 묻지 않는다. 빠진 것만 AskUserQuestion으로 한 번에 묻는다. 각 질문에는 "네가 정해줘" 보기를 꼭 넣는다.

1. **하고 싶은 일(직무)**: 콘텐츠 마케터 / 브랜드·공간 마케터 / MD·온라인 영업 / CX / 서비스 기획·개발·데이터 분석 / 교육 회사 운영·기획 / 아직 모름
2. **조사할 것**: 광고 소재 / 경쟁사 가격 / 증정품·프로모션 / 상세페이지 / 팝업스토어 / 교육 프로그램 / 경쟁 서비스 기능 / 네가 정해줘. 보기에 없는 것을 적으면 그대로 쓴다.
3. **회사와 고객**: 회사(브랜드)와 업종, 고객이 누구이고 어떤 상황인지
4. **경쟁사 3곳**: 직접 적기 / 네가 정해줘

추가로 받을 수 있는 것: 근거로 삼을 **채용공고 링크**. 사용자가 공고를 주면 그 공고의 주요업무·자격요건·우대사항에서 조사할 것을 뽑는다.

사용자가 "되묻지 마"라고 했거나 CLAUDE.md에 그런 규칙이 있으면 묻지 않는다. 그때는 CLAUDE.md의 '나와 회사' 줄과 아래 기본값으로 가정하고, 가정한 곳에 (가정)을 붙인다. 사용자가 자리에 없을 때도 같다.

## 2단계. 정해지지 않은 것 고르기

**조사할 것이 "네가 정해줘"이면** 직무에 맞춰 고른다.
| 직무 | 조사할 것 |
|---|---|
| 마케터(콘텐츠·퍼포먼스 등) | 광고 소재 |
| MD·온라인 영업 | 경쟁사 가격 + 증정품·프로모션 |
| 브랜드·공간 마케터 | 팝업스토어 |
| CX | 상세페이지 |
| 서비스 기획·개발·데이터 분석(테크 트랙) | 경쟁 서비스 기능(자사몰·앱 기능) |
| 교육 회사 운영·기획 | 교육 프로그램(커리큘럼, 강사진, 운영안) |
| 그 밖의 일, 아직 모름 | 경쟁사 가격 + 증정품·프로모션 |

**경쟁사가 "네가 정해줘"이면** 우리와 같은 고객을 두고 경쟁하는 곳 3곳을 웹 검색으로 고른다. 우리보다 훨씬 큰 대기업은 뺀다. 사용자가 직접 준 경쟁사는 그대로 쓰되, 아주 큰 회사이거나 그 조사 항목이 거의 없을 것 같으면 표에 한 줄로 적는다.

**회사가 조사할 것과 맞지 않으면**(예: 교육 프로그램인데 아이스크림 회사) 그 일이 있는 비슷한 가상의 회사로 바꾼다. 사용자에게 한 줄로 알리고, 바꾼 회사를 mvp.md 맨 위와 CLAUDE.md의 회사 줄에 적는다.

## 3단계. 짧게 확인 조사

- 경쟁사 3곳이 실제로 무엇을 파는지 웹 검색으로 확인한다(대표 제품 이름 정도).
- 그 조사 항목을 실제로 어디서 찾을 수 있는지 확인한다(예: 팝업은 팝가, 광고는 메타 광고 라이브러리).
- 우리 회사의 같은 항목 기준점(예: 최근 팝업, 대표 광고)이 있으면 1개 찾아 출처와 함께 적는다.
- 채용공고를 근거로 쓸 때는 사람인·잡코리아·리멤버·원티드에서 찾고, 원문을 열어 문장을 확인한다. 열지 못한 문장에는 (가정)을 붙인다.

## 4단계. mvp.md 쓰기 (한 장)

맨 위: 회사(바꿨으면 바꾼 회사), 하고 싶은 일, 조사할 것, 고객, 작성일.

칸(섹션)은 아래 6개를 이 순서로 쓴다.

1. **누가, 언제, 왜 이 조사를 매일 하나**: 누가(직무), 언제(예: 출근 직후, 회의 전), 왜(고객 상황과 연결), 지금 손으로 하면 하루 몇 분인지와 그 내역. 모르면 (가정).
2. **경쟁사 3곳과 고른 이유**: 경쟁사마다 대표 제품과 우리 고객과 겹치는 이유 한두 줄.
3. **표에 적을 칸 5~7개 + 칸마다 어디서 찾나**: 칸 이름 / 적는 방법 / 어디서 찾나 / 못 찾을 수 있음?. 마지막에 '출처 링크·조사한 날짜' 칸을 꼭 붙인다. 표 한 줄이 무엇 1개인지 적는다.
4. **만들지 않을 것 3가지**: 로그인 자동 수집, 대시보드·알림·자동 실행, 근거 없는 숫자 추정 같은 것.
5. **확인할 숫자 2가지**: 걸린 시간(분), 못 찾은 칸 수 ÷ 전체 칸 수. 손으로 할 때 값도 함께.
6. **성공 기준**: 예) 걸린 시간 10분 이하, 못 찾은 칸 30% 이하, 모든 값에 출처와 날짜, 지어낸 값 0개, 같은 형식으로 반복. 조사 결과로 얻고 싶은 한 줄(예: "우리가 비어 있는 메시지")도 넣는다.

### 조사할 것별 칸 예시 (5~7개에서 고르고 맞게 고친다)

- **광고 소재**: 브랜드·채널 / 게재 시작일 / 형식(릴스 초, 이미지, 캐러셀 장 수) / 훅(첫 3초·첫 줄) / 핵심 메시지(고객 걱정과 연결) / 등장 인물 / 행동 유도·혜택
- **경쟁사 가격**: 제품명 / 용량(g, ml 단위까지) / **판매처(몰)** / 정가 / 판매가 / 할인율 / 확인 시각
- **증정품·프로모션**: 판매처(몰) / 행사 이름 / 기간 / 조건(얼마 이상 구매 등) / 증정품과 용량(g, ml) / 할인·쿠폰
- **상세페이지**: 제품 / 첫 화면 문구 / 내세우는 효능 / 근거(시험·인증) / 사용법 안내 / 후기 배치 / 구매 유도 장치
- **팝업스토어**: 브랜드 / 팝업 이름·콘셉트 / 기간 / 장소(상권+건물+층) / 체험 프로그램 / 현장 혜택 / 예약·입장 방식
- **교육 프로그램**: 과정명 / 대상 / 커리큘럼(회차별 주제) / 강사진 / 운영 방식(온·오프, 기간) / 가격 / 수료 혜택
- **경쟁 서비스 기능**: 서비스(자사몰·앱) / 기능 이름 / 어디에 있나(화면 위치) / 무엇을 해 주나 / 로그인 필요 여부 / 우리와 다른 점

### 꼭 지킬 규칙

- 가격을 조사하면 **판매처(몰) 칸을 꼭 넣는다**. 같은 제품도 몰마다 값이 다르다. 용량은 단위(g, ml)까지 적게 한다.
- 로그인해야 보이는 값, 자동 접속을 막는 쇼핑몰의 실시간 가격, 현장에서만 알려 주는 정보처럼 웹에서 찾기 어려운 칸에는 **"못 찾을 수 있음"**이라고 적는다.
- 추측한 곳에는 **(가정)**, 찾지 못한 값은 **"못 찾음"**. 숫자, 가격, 후기를 사실처럼 꾸미지 않는다.
- 웹에서 찾은 값에는 조사한 날짜와 출처 링크를 붙인다.
- 표(CSV)는 UTF-8 BOM으로 저장하고, 쉼표·큰따옴표·줄바꿈이 든 값은 큰따옴표로 감싼다고 mvp.md에 적는다.

## 5단계. 한눈에 보는 HTML 만들기

mvp.md 내용을 그대로 한 페이지 HTML로 만들어 artifact로 publish한다. 구성:

1. 머리: 한 줄 제목(예: "경쟁 ○○ 광고 소재, 매일 45분 → 10분"), 회사·직무·작성일, 칩(조사할 것, 경쟁사 3곳, 표 칸 수, (가정) 뜻)
2. 숫자 카드 4개: 지금 손으로 몇 분 / 목표 / 못 찾은 칸 기준 / 지어낸 값 0개
3. ① 누가·언제·왜 + 손으로 하는 시간을 나눈 가로 막대
4. ② 경쟁사 카드 3개
5. ③ 표 칸 테이블(못 찾을 수 있는 칸에는 회색 표시)
6. ④ 만들지 않을 것 / ⑤ 확인할 숫자 / ⑥ 성공 기준을 세 칸으로 나란히

(가정)은 노란 작은 표시로, "못 찾을 수 있음"은 회색 작은 표시로 구분한다. 밝은 화면과 어두운 화면 모두에서 읽히게 하고, 모바일에서는 한 줄씩 쌓이게 한다.

## 6단계. 저장과 보고

- mvp.md는 파일로 저장한다. 사용자가 쓰는 저장 위치(연결된 폴더나 구글 드라이브의 수업 폴더)가 있으면 그곳에도 넣고, 같은 이름의 예전 파일은 휴지통으로 옮긴다.
- 조사할 것이나 직무가 바뀌어 다시 만들면 mvp.md와 HTML을 둘 다 고친다(HTML은 같은 artifact를 다시 publish).
- 끝나면 **"조사할 것", "경쟁사 3곳", "표에 적을 칸"**만 보여 준다. 사용자가 다른 보고 형식을 정했으면 그것을 따른다(예: 만든 파일 / 핵심 한 줄 / 다음에 할 일).
