# mvp.md — 경쟁사 광고 소재(콘텐츠) 리서치 조사 설계서

- 회사: 메디큐브 (뷰티 디바이스). 메디큐브도 SNS 광고와 콘텐츠를 꾸준히 올리는 브랜드라 회사는 바꾸지 않았어요.
- 하고 싶은 일: 콘텐츠 마케터 (팝업스토어 조사에서 콘텐츠 마케팅 쪽으로 바꿈)
- 조사할 것: 광고 소재. 경쟁사가 SNS에 올리는 광고와 콘텐츠를 조사해요. 콘텐츠·마케터 직무는 '광고 소재'를 조사하기로 한 규칙을 따랐어요.
- 고객: 관리를 하고 싶고 받고 싶지만 시간이 없고 부작용도 무서운 2535 여성. 퇴근 후 쉬면서 간단하게 관리하고 싶어요.
- 작성일: 2026-11-16

---

## 1. 누가, 언제, 왜 이 조사를 매일 하나

| 항목 | 내용 |
|---|---|
| 누가 | 메디큐브 콘텐츠 마케터 (주니어 1명) (가정) |
| 언제 | 매일 아침 출근 직후, 그날 콘텐츠 기획 회의 전 |
| 왜 | 경쟁사가 지금 어떤 훅(첫 3초 문구)과 메시지로 우리 고객에게 말을 거는지 알아야 해요. 그래야 겹치지 않는 메시지를 고르고, "시간이 없다", "부작용이 무섭다"는 고객의 걱정에 먼저 답하는 콘텐츠를 만들 수 있어요. |
| 지금 손으로 하면 | 하루 약 45분 (가정): 메타 광고 라이브러리에서 경쟁사 3곳 검색 15분 + 인스타 릴스·유튜브 쇼츠 훑기 15분 + 화면 캡처·엑셀 정리 15분 |

## 2. 경쟁사 3곳과 고른 이유

경쟁사는 사용자가 정해 준 대로 썼어요.

| 경쟁사 | 고른 이유 |
|---|---|
| 마미케어 | EMS 브이쎄라, 펜타프라임 같은 홈케어 디바이스 브랜드예요. 캐릭터 콜라보와 증정품을 내세운 소재가 많아서, 2535 여성을 두고 메디큐브와 직접 경쟁해요. |
| 뉴스킨 | 에이지락 라인 같은 홈 뷰티 디바이스를 파는 글로벌 브랜드예요. 회원·방문 판매 중심이라 브랜드 공식 광고보다 회원 개인 콘텐츠가 많을 수 있어요 (가정). 메디큐브보다 훨씬 큰 회사예요. |
| 바나브 | UP6 갈바닉, UP7 더 멀티, 버블팝 클렌저로 "집에서 에스테틱처럼"을 내세워요. 퇴근 후 간단하게 관리하고 싶은 우리 고객과 겹쳐요. |

## 3. 표에 적을 칸 (7개) + 칸마다 어디서 찾나

표 한 줄 = 광고 소재 1개. 경쟁사마다 최근 소재 3~5개를 적어요. 소재가 없으면 그 경쟁사 줄에 "최근 소재 못 찾음"이라고 적어요.

| # | 칸 이름 | 적는 방법 | 어디서 찾나 | 못 찾을 수 있음? |
|---|---|---|---|---|
| 1 | 브랜드·채널 | 경쟁사 이름 + 채널 (메타 광고 / 인스타 / 유튜브 쇼츠 / 틱톡) | 메타 광고 라이브러리, 브랜드 공식 계정 | — |
| 2 | 게재 시작일 | YYYY-MM-DD | 메타 광고 라이브러리의 '게재 시작', 게시물 날짜 | — |
| 3 | 형식 | 릴스(영상, 길이 초) / 이미지 / 캐러셀(장 수) | 광고 라이브러리, 게시물 | — |
| 4 | 훅 (첫 3초·첫 줄) | 영상 첫 자막이나 광고 첫 문장을 그대로 | 광고 라이브러리 미리보기, 게시물 | 영상 안 자막만 있으면 못 찾을 수 있음 |
| 5 | 핵심 메시지 | 무엇을 내세우나 한 줄 + 고객 걱정과 연결 (시간 절약 / 부작용·안전 / 효과 / 가격·혜택) | 광고 문구, 캡션 | — |
| 6 | 등장 인물 | 모델 / 인플루언서 / 일반인 후기(UGC) / 제품만 | 소재 화면 | — |
| 7 | 행동 유도·혜택 | 버튼 문구 + 증정품·할인. 증정품 용량은 단위(ml, g)까지 | 광고 버튼, 캡션, 연결된 상세페이지 | 로그인해야 보이는 쿠폰가는 못 찾을 수 있음 |
| + | 출처 링크·조사한 날짜 | 소재마다 링크 1개 이상 + 확인 날짜 | — | — |

- 표는 CSV로 저장해요. 엑셀에서 한글이 깨지지 않게 UTF-8 BOM으로 저장하고, 쉼표·큰따옴표·줄바꿈이 든 값은 큰따옴표로 감싸요.
- 못 찾은 값은 "못 찾음", 추측한 값에는 (가정)이라고 적어요.
- 광고 성과(노출수, 클릭, 매출)는 공개되지 않아서 적지 않아요. 일반 게시물의 조회수·좋아요는 보이면 메모로만 적어요.

## 4. 만들지 않을 것 3가지

1. 로그인이 필요한 인스타·틱톡 계정 자동 수집. 막히기 쉽고 계정이 위험해질 수 있어요.
2. 광고 이미지·영상 파일을 내려받아 모아 두는 기능. 링크와 문구만 적어요.
3. 경쟁사 광고 성과나 광고비 추정. 근거 없는 숫자를 만들지 않아요.

## 5. 확인할 숫자 2가지

| 숫자 | 재는 방법 | 손으로 할 때 |
|---|---|---|
| 걸린 시간 (분) | 에이전트에 조사를 시킨 순간부터 표가 저장될 때까지 | 약 45분 (가정) |
| 못 찾은 칸 수 / 전체 칸 수 | 표에서 "못 찾음" 칸을 센다 | 처음에 한 번 손으로 재서 비교 기준으로 삼기 |

## 6. 성공 기준

- 걸린 시간 10분 이하 (손으로 할 때의 약 4분의 1) (가정)
- 못 찾은 칸이 전체 칸의 30% 이하 (소재가 아예 없는 경쟁사는 빼고 셈)
- 경쟁사마다 최근 소재 3개 이상
- 적은 값 모두에 출처 링크와 조사한 날짜가 붙어 있음 (100%)
- 지어낸 값 0개: 출처 링크를 열어 보면 같은 문구가 있어야 함
- 결과 끝에 "우리가 비어 있는 메시지" 한 줄 (예: 경쟁사 아무도 '부작용 걱정'을 말하지 않음)
