3표에 적을 칸 7개와 찾는 곳

#칸적는 방법어디서 찾나
1브랜드·채널경쟁사 + 채널 (메타 광고 / 인스타 / 유튜브 쇼츠 / 틱톡)메타 광고 라이브러리, 브랜드 공식 계정
2게재 시작일YYYY-MM-DD광고 라이브러리 '게재 시작', 게시물 날짜
3형식릴스(길이 초) / 이미지 / 캐러셀(장 수)광고 라이브러리, 게시물
4훅영상 첫 자막이나 광고 첫 문장 그대로광고 미리보기, 게시물못 찾을 수 있음
영상 안 자막만 있을 때
5핵심 메시지한 줄 + 고객 걱정과 연결 (시간 절약 / 부작용·안전 / 효과 / 가격·혜택)광고 문구, 캡션
6등장 인물모델 / 인플루언서 / 일반인 후기(UGC) / 제품만소재 화면
7행동 유도·혜택버튼 문구 + 증정품·할인. 증정품 용량은 ml, g까지광고 버튼, 캡션, 연결된 상세페이지못 찾을 수 있음
로그인해야 보이는 쿠폰가
+출처·조사한 날짜소재마다 링크 1개 이상 + 확인 날짜—

표 한 줄 = 광고 소재 1개 · 경쟁사마다 최근 소재 3~5개 · 소재가 없으면 "최근 소재 못 찾음" · 못 찾은 값은 "못 찾음", 추측한 값은 (가정) · CSV는 UTF-8 BOM으로 저장하고 쉼표·따옴표·줄바꿈이 든 값은 큰따옴표로 감싸기 · 광고 성과(노출·클릭·매출)는 공개되지 않아 적지 않기

4만들지 않을 것

  • ✕로그인이 필요한 인스타·틱톡 자동 수집. 막히기 쉽고 계정이 위험해질 수 있어요.
  • ✕광고 이미지·영상 파일 내려받기. 링크와 문구만 적어요.
  • ✕경쟁사 광고 성과·광고비 추정. 근거 없는 숫자는 만들지 않아요.
