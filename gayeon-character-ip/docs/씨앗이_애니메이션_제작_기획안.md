# 씨앗이 애니메이션 제작 가이드

Nov 3, 2026 · @가연

씨앗이 우체국 세계관으로 애니메이션을 만들 때, 목소리·표정·성격 세 가지 일관성을 어떻게 잡을지 정리한 가이드예요.

Claude는 사용자가 직접 **파인튜닝(재학습)할 수 없어요.** 대신 프로젝트에 자료를 넣어두면, 매 대화마다 그 자료를 읽고 씨앗이를 일관되게 다룹니다. 목소리와 그림은 전용 도구가 맡고, Claude는 기획·대본·프롬프트를 맡는 구조예요.

| 목표 | 담당 도구 | Claude의 역할 |
| --- | --- | --- |
| 목소리 TTS | 음성 생성 서비스 / 오픈소스 음성 모델 | 보이스 디자인 프롬프트, 대사 낭독 지시 |
| 표정·외형 일관성 | 이미지 생성 도구 (LoRA, 레퍼런스 기능) | 표정별 프롬프트 사전, 컷 연출 |
| 성격·대본 일관성 | Claude 프로젝트 | 기획안·대본 직접 작성 |

## 1. 목소리 TTS

목소리는 Claude가 학습하거나 생성하지 못해서, 음성 생성 서비스나 오픈소스 음성 모델을 써야 해요.

**주의:** 특정 애니메이션 캐릭터의 목소리를 그대로 학습시키는 건 피하는 게 좋아요. 그 목소리는 성우 본인의 것이라, 동의 없이 복제하면 퍼블리시티권·저작권 문제가 생길 수 있고, 대부분의 TTS 서비스도 약관상 금지해요. 콘텐츠로 공개할 경우에는 더 주의가 필요해요.

대안:

- **보이스 디자인**: "작고 밝은, 살짝 수다스러운 목소리"처럼 설명으로 새 목소리를 만들기
- **직접 녹음 / 성우 섭외**: 본인, 지인, 또는 외주 성우에게 동의를 받고 녹음한 뒤 그 목소리로 클론
- **느낌만 참고하기**: 원하는 애니 목소리의 톤·속도·높이를 말로 정리하면, Claude가 보이스 디자인용 프롬프트로 바꿔드릴 수 있어요

## 2. 표정·외형 일관성

이미지 일관성은 이미지 생성 도구에서 잡아야 하고, 핵심은 직접 그린 **모델 시트**예요.

1. **모델 시트 만들기**: 정면·측면·뒷모습 + 표정 시트(기쁨, 뿌듯, 속상, 놀람, 졸림, "뽀짝!" 표정 등)를 원본 그림으로 10~20장 준비
2. **캐릭터 학습**: 그 이미지로 LoRA를 학습시키거나(Stable Diffusion/Flux 계열), 레퍼런스 이미지 기능이 있는 도구 사용
3. **항상 같은 특징 고정**: 노란 가방, 몸 비율, 색상 코드를 모든 프롬프트에 명시

Claude의 역할: 표정별 **텍스트 프롬프트 사전**, 장면별 연출 지시, 컷 구성을 일관되게 작성하는 것.

## 3. 성격 일관성 → 기획안·대본

이 부분은 Claude가 바로 맡을 수 있어요. 프로젝트에 아래 문서들을 넣어두면 돼요.

| 문서 | 담을 내용 |
| --- | --- |
| 캐릭터 바이블 | 성격, 말버릇("뽀짝!"), 좋아하는 것(해바라기씨), 속상할 때 털어내는 방식, 절대 하지 않는 말 |
| 세계관 문서 | 마을, 우체국, 주민들, 계절 이벤트 |
| 말투 예시 대사 | 20~30개. 좋은 예와 씨앗이답지 않은 예를 함께 |
| 대본 포맷 템플릿 | 러닝타임, 장면 구성, 지문 스타일 |
| 프로젝트 지침 | "대본을 쓸 때는 항상 캐릭터 바이블을 따른다" 같은 규칙 |

지금까지 정한 설정(고향 가족을 그리워하는 우체부, 말장난·TMI를 좋아함, 남에게 잘 기대지 않는 성격 등)이 이미 탄탄해서, 캐릭터 바이블 초안을 바로 만들 수 있어요.

## 4. 유튜브 알고리즘을 타는 콘텐츠 설계

2026년 유튜브 추천은 키워드보다 **시청자 만족도와 시청 지속률**을 가장 크게 봅니다. 그래서 블로그 SEO처럼 태그를 채우기보다, "끝까지 보고 마음이 따뜻해지는 영상"을 설계하는 게 핵심이에요. 태그는 사실상 영향이 거의 없고, 클릭률만 높고 내용이 약하면 오히려 추천이 줄어듭니다.

### 알고리즘 신호별 씨앗이 적용법

| 신호 | 알고리즘이 보는 것 | 씨앗이 콘텐츠에 적용 |
| --- | --- | --- |
| 클릭률(CTR) | 썸네일·제목을 보고 누르는가 | 씨앗이의 큰 표정 + 짧은 공감 문구("오늘 아무한테도 연락 안 온 날"). 제목과 내용을 일치시키기 |
| 초반 30초·시청 지속률 | 어디서 이탈하는가 | 첫 3초에 공감 대사나 상황을 바로. 인트로·로고는 짧게 |
| 만족도 | 좋아요·공유·저장·설문·"관심 없음" | 마지막에 씨앗이가 시청자에게 주는 짧은 편지 한 줄 → 저장·공유하고 싶은 마무리 |
| 세션·재방문 | 다음 영상을 이어서 보는가 | "오늘의 편지" 같은 고정 시리즈 + 재생목록, 매주 같은 요일 업로드 |
| 참여 | 댓글·투표 | "여러분의 오늘은 어땠나요?" 질문, 댓글 사연에 다음 화에서 답장 |

### 포맷: 쇼츠 + 롱폼 함께

- **쇼츠(30~60초)**: 새 시청자를 들이는 발견용. 말장난 한 방, "뽀짝!" 리액션, 공감 한 장면
- **롱폼(5~10분)**: 팬으로 만드는 에피소드. 마을 주민의 사연 → 씨앗이의 편지 구조
- 쇼츠와 롱폼을 함께 운영하는 채널이 한쪽만 하는 채널보다 빨리 성장한다는 분석이 많아요.

### 씨앗이 설정과 연결되는 공감 테마

씨앗이의 이미 정해진 성격에서 나오는 이야기라서, 트렌드를 따라가도 캐릭터가 흔들리지 않아요.

| 공감 테마 | 씨앗이 설정 연결고리 | 에피소드 예시 |
| --- | --- | --- |
| 타지살이·자취의 외로움 | 고향 가족을 그리워하는 우체부 | 명절에 고향 못 가는 날, 씨앗이가 혼자 사는 주민에게 편지를 전함 |
| 자존감 낮은 날 | 가끔 자신이 볼품없다고 느낌 | 실수한 날, 씨앗이가 쳇바퀴를 돌리며 털어내는 법 |
| 남에게 기대지 못하는 사람 | 속상해도 잘 기대지 않음 | 편지만 주던 씨앗이가 처음으로 편지를 받는 날 |
| 매일의 피로·월요병 | 매일 새 소식을 전하는 일상 | 비 오는 월요일 배달길 |
| 소소한 행복 | 해바라기씨, 애니·영화 보기 | 퇴근 후 해바라기씨 한 봉지의 행복 |
| 시즌·시사 | 쉽고 친근한 뉴스 코너 | 수능·연말·첫눈 등 시기에 맞춘 편지 |

### 주의할 점

- **AI 사용 표시**: AI 음성·AI 이미지를 쓰면 업로드 시 AI 콘텐츠 공개 표시를 해야 해요. 표시하지 않으면 추천·검색에서 불이익을 받을 수 있어요.
- **냚시 피하기**: 제목이 호기심을 끌되, 영상이 그 약속을 지켜야 해요.
- **트렌드보다 캐릭터 우선**: 유행 밈을 넣더라도 씨앗이가 할 법한 말로만.

## 5. 나가노 작가식 세계관: 귀여운 표면 속 현실의 그늘

핵심은 **동화 같은 마을에 현실의 시스템을 그대로 옮겨놓고, 설명하지 않고 보여주기만 하는 것**이에요. 치이카와의 캐릭터들은 제초·토벌 같은 노동으로 먹고살고, 더 나은 보수를 위해 자격시험을 봅니다. 한국의 20대 직장인 관객들이 "귀엽지만 어두운 결이 있고, 그 안에서 내 모습이 보인다"고 말하는 이유가 여기 있어요.

단, 따라갈 것은 **기법과 태도**이지 설정 자체가 아니에요. 토벌·자격시험·괴물로 변하는 설정 같은 치이카와 고유 요소는 가져오지 않고, 씨앗이 우체국만의 현실을 만드는 게 좋아요.

### 기법별 씨앗이 적용

| 나가노식 기법 | 씨앗이 우체국 버전 |
| --- | --- |
| 현실 노동 시스템을 동화 세계에 이식 | 배달 건수제 월급, 우체부 승급 심사, 편지가 줄어 마을 우체국이 통폐될지도 모른다는 소문 |
| 가난과 빈부를 배경으로만 보여주기 | 씨앗이의 작은 방, 해바라기씨를 세어보고 내일 먹을 만큼 남겨두는 버릇, 고향에 보내는 소포 |
| 말하지 못하는 것, 침묵 | 수다쟁이 씨앗이가 정작 자기 얘기만은 안 함. TMI와 말장난으로 화제를 돌린다 |
| 어두운 한 컷 뒤 바로 밝은 일상 | 아무도 찾아가지 않는 편지 더미를 한 컷 비추고, 다음 컷에서 "뽀짝!" 하며 간식 시간 |
| 자조적 셀프 태클 유머(농담곰 톤) | "오늘도 아무도 나한테는 편지 안 썼네~ 내가 우체부인데 뽀짝!" 같은 웃픈 대사 |
| 함께 먹는 작은 보상 | 힘든 날 끝에 누군가와 해바라기씨를 나눠 먹는 장면을 에피소드의 고정 마무리로 |

### 에피소드 구조 (현실 공감 + 응원)

1. **귀여운 일상**: 배달, 말장난, 마을 주민과의 수다
2. **현실의 스침**: 설명 없는 한 장면. 반송 도장, 배달량이 적힌 표, 혼자 먹는 저녁
3. **씨앗이의 대처**: 해결하지 못해도 챙바퀴·해바라기씨·영화로 털어내기
4. **작은 연결**: 누군가의 편지, 나눠 먹는 간식. 문제는 그대로지만 오늘은 조금 괜찮음
5. **시청자에게 한 줄 편지**: 응원을 가르치지 않고 곁에 있어주는 말투로

### 어둠의 수위 가이드

- **비율**: 밝음 8 : 그늘 2 정도. 씨앗이 우체국은 힐링이 중심이라 치이카와보다 연하게
- **암시만 하기**: 숨겨진 디테일을 찾는 재미가 댓글·재시청으로 이어져요 (알고리즘 만족도 신호와도 맞물림)
- **피할 것**: 잔인한 묘사, 죽음·자해를 연상시키는 장면, 절망으로 끝나는 에피소드. 힘든 사람이 보는 채널이라는 점을 기준으로

### 에피소드 예시

| 제목(가제) | 현실의 스침 | 응원 포인트 |
| --- | --- | --- |
| 승급 심사 날 | 씨앗이만 또 떨어짐. 합격자 명단을 오래 보는 뒷모습 | 떨어진 날에도 편지는 배달되고, 받은 주민이 고맙다고 함 |
| 반송함 | 주소가 없어져 돌아온 편지들, 사라진 이웃 | 씨앗이가 기억력으로 받는 사람을 찾아감 |
| 명절 근무 | 명절에도 고향에 못 감. 전화기 너머 가족에게 "나 잘 지내!" | 마을에 남은 주민들과 해바라기씨 한 상 |
| 우체국이 없어진대 | 편지량 감소, 통폐 소문 | 그래도 편지를 기다리는 사람이 있다는 발견 |
